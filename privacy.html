Privacy Policy

howitclicks studio · Last updated 22 November 2026

Who this applies to

howitclicks studio is a personal tool used only by the owner of the How It Clicks YouTube channel, on the owner's own computer. It has no other users and does not collect information from viewers or the public.

What the app accesses

With the channel owner's permission, granted through Google sign-in, the app uses YouTube API Services to:

  • upload the channel's own videos and set their titles, descriptions, schedules and thumbnails (YouTube Data API);
  • read the status of those videos;
  • read analytics for the channel's own videos, such as views, watch time and impressions (YouTube Analytics API).

It does not access any other channel, any viewer's account, or any personal data of other people.

How data is stored and used

  • The Google access token and the analytics figures are stored only on the owner's own computer.
  • Analytics figures are used only to improve future videos on this channel.
  • No data is sold, shared with third parties, or used for advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

This app uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time on the Google Account permissions page. Locally stored data is deleted when the owner removes it from their computer.

Contact

Questions: contact the channel through the How It Clicks YouTube channel.
